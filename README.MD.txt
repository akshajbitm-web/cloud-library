# 📚 Online Library Management System

> A simple Python-based terminal library system with login authentication, account creation, book logging, and reading history tracking.

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey)
![License](https://img.shields.io/badge/Status-Student%20Project-green)

---

## ✨ Features

- 👤 User Login System
- 🆕 Create New Account
- 🔒 Password Authentication with Login Attempt Limit
- 📚 View Available Books
- 📝 Log Books as Fully or Partially Read
- 📖 View Personal Reading History
- 📂 Automatic Folder & File Creation
- 🖥️ Simple Terminal Interface

---

## 🧠 How It Works

The program stores usernames and passwords in a text file and tracks:

- User login attempts
- Books available in the library
- Reading history for each user

1. See All Books
2. Log a Book
3. See My Books
